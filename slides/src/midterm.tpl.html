From excavation report to site image: what we measured so far

In the proposal the plan on the cover was built by hand. This time the language model read the Hebrew text and produced the layout, and the same layout guided the image on the right. The talk has four parts: what changed since the proposal, what the data look like, first results against baselines, and where the system fails.

The project in one slide

Given a written excavation report, produce a spatial layout in which every element is backed by a quote, generate a top-down image from it, and measure what in the image the report does not support.

Unchanged: the research question, the three conditions, the three lenses, and the rule that unknown positions stay unknown.

Six changes, each with its evidence. The network trained only on generated images finds no wall on real tiles, so the question of part B becomes: does generated pre-training help when a few real tiles exist? The fourteen development tiles are now also used for fine-tuning. The automatic meter gives no credit for pits and counts installations only as something built, so the human audit moves up. The prompt and the class mapping are under test, because every image has a wall that the layout does not have. The text leaves positions open, so a strict IoU punishes correct readings. The analysis of the generated set led to a second version. And the plan condition waits for consent. The research question, the conditions and the rule that unknown stays unknown did not change.

Too little variety. All 300 layouts share two seeds, and two different layouts with the same seed look more alike than one layout with two seeds. Decision: a unique seed per image in version 2.

Two findings. First, the label is noisy, because diffusion does not draw the mask exactly. SegFormer says the median agreement is about 0.24; a U-Net trained on the other half of the data says about 0.68. The two signals almost do not correlate, so I do not use either to delete images. Second, and this surprised me: two different layouts with the same diffusion seed look more alike than the same layout with two seeds. I used only two seeds for all layouts, so the set has less variety than six hundred images suggest. Version two will use a unique seed per image.

The real set. Fifty-six tiles with wall outlines from drone photos in Israel. Before using them I checked for leakage. The first look at the research question, and the answer is mixed. More of the layout is drawn: recall rises with the language model's layout in all five cases, and a hand-built layout does better still. But the mean IoU to the text layout, which I defined as a main metric, goes down in four of the five cases, for the hand-built layout too. The reason is visible in the classes. The IoU of built things rises and the IoU of the ground falls, because the generator fills empty ground with walls. Text alone draws almost nothing built, so its ground is nearly right by default. So the layout transfers information and the generator adds to it, and the second effect is larger in this metric. With five cases the exact test cannot go below p of six percent, so this is descriptive. Note also what recall counts: walls and installations as one group; pits get almost no credit in any condition.

The segmentation results, and they are not what I hoped for. On the generated test set the U-Net is far above the zero-shot models, although that number is optimistic, because the test images share diffusion seeds with the training images. On real tiles the same network finds no wall at all, in all three seeds. I checked that it is not a bug, and simple adaptations on the development tiles did not help either. Fourteen real tiles are enough to reach about 0.44; two labels of the same photo agree at about 0.7. Pre-training on generated images did not help: the difference is slightly negative in all three seeds. The strongest untrained model is a two-threshold rule, so I compare with it and not only with Grounded-SAM. Two cautions: the intervals are approximate, and tiles do not name their site, so a new site could be harder.
