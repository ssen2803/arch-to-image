# ביקורת אנושית של מדד ההזיות (#6, measurement_HOR.md סעיף 6.4)

30 תמונות שנוצרו בשלב 3, 6 מכל דוגמה: 3 של ControlNet, 2 של GLIGEN ו-1 בלי פריסה. הן מוצגות בסדר אקראי, וזהות התנאי והציונים שמורים ב-`key.json`. **לא לפתוח את key.json לפני שמסיימים לדרג.**

כל קובץ ב-`items/` מכיל שלושה חלקים:
1. התמונה שנוצרה.
2. אותה תמונה, עם האזורים שהמדד סימן כ"מומצאים". לכל אזור צבע ומספר.
3. מה שהפריסה ביקשה (קיר חום, רצפה צהבהבה, מתקן אדום, בור כחול).

## מה ממלאים

**[components.csv](components.csv), שורה לכל אזור ממוספר (171 בסך הכול):** בעמודה `real_a`:
- **1:** האזור הוא באמת אובייקט או מבנה שלא קיים בפריסה. למשל קיר שסוגר חדר, ערימת אבנים או טקסט.
- **0:** האזור אינו המצאה. למשל חלק מאלמנט שכן נמצא בפריסה, צל, מרקם קרקע, או טעות של המקטע.

**[missed.csv](missed.csv), שורה לכל תמונה:** בעמודה `missed_hallucinations_a` כותבים כמה אובייקטים מומצאים רואים בתמונה **בלי** מספר עליהם.

מתייג שני ממלא את העמודות `_b`, בלי לראות את הדירוג של הראשון. לפי הפרוטוקול, 20% מהתמונות לפחות צריכות לקבל שני מתייגים.

## חישוב

```bash
..\.venv\Scripts\python src/audit_sample.py --score
```

הסקריפט מדווח:
- **precision:** איזה חלק מהאזורים שהמדד סימן הם באמת המצאה.
- **recall:** איזה חלק מההמצאות שבתמונה המדד תפס.
- **Cohen's κ:** ההסכמה בין המתייגים.

לפי הפרוטוקול, אם ה-precision נמוך מ-0.8 צריך לכוונן את המעריך לפני דיווח סופי.
